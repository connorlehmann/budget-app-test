# Finance Tracker Architecture

## Overview
Finance Tracker is a Flask web app that allows users to add delete, and track their expenses. You are also able to calculate totals and recurring costs.

## Tech Stack
- Python
- Flask
- Flask-WTF
- HTML
- CSS
- Jinja2
- JSON (temporary data storage)

## Features
- Add expenses
- Delete expenses
- View expenses
- Calculate total
- Track recurring bills

## Future Improvements
- User accounts
- PostgreSQL database
- Cloud deployment
- Budget tracking
- Expense charts
